Anchor · v1.2.0

Paused should mean paused.

Anchor automatically detects web video and audio players on HTTP and HTTPS sites, including your Jellyfin server and players embedded from other hosts. A deliberate pause stays held until you choose Play. You can turn protection off for an individual site.

Install or update in Brave / Chrome

  1. Use the Anchor folder in the extracted repository folder, or extract Anchor.zip to a permanent folder.
  2. Open brave://extensions in Brave or chrome://extensions in Chrome. Enable Developer mode.
  3. Click Load unpacked and select the folder containing manifest.json. To update an existing installation from this folder, click its Reload button.
  4. Approve website access if the browser asks; automatic detection across sites and iframe hosts needs HTTP/HTTPS access.
  5. Reload already-open streaming tabs and pin Anchor using the browser's extension menu.

What the icon means

White on black: an enabled player with a media source is detected. Gray: protection is off, no playable media is detected, the media source failed, or this page cannot host extensions. A black icon confirms detection, not a test of a service's entire player implementation.

Playback and media keys

  • Pause with a recognized player control or Space / K. Play releases the pause latch.
  • Keep paused forces the whole tab to pause, including players that load afterward. Resume releases the latch and starts the main detected player.
  • Use hardware Play/Pause, Play, Pause, or Stop. Stop holds the video without resetting its position. Media keys also work while typing.
  • Anchor registers fallback Media Session play/pause/stop handlers for players that have none. It preserves the site's own handlers and restores them when disabled. The OS or browser chooses which app or tab receives hardware media actions.
  • Optional quick toggle: assign your own shortcut at brave://extensions/shortcuts or chrome://extensions/shortcuts.
  • ← / → seeks 10 seconds. Space / K and seeking avoid text fields, sliders, menus, focused buttons and links.

Optional preferences

  • Stop autoplay & next episodes: holds a new page paused and holds it again when the primary media ends. This may also stop ad-to-content transitions.
  • Lock every pause: catches unrecognized and programmatic pauses. It can interrupt buffering or source transitions.
  • Pause when leaving this tab: holds a playing video when the document becomes hidden. Returning does not automatically resume.

Troubleshooting

For an unfamiliar pause control, use Keep paused and Resume, or enable Lock every pause. Some native browser video controls hide their click events from extensions; use the popup or media keys with those players.

If a player shows an autoplay warning while held, explicitly resume. After reloading, the browser may require clicking the site Play button once before popup Resume can work. If media keys control another tab or app, make your streaming tab the active media session by playing it once. OS media routing and apps that reserve hardware keys remain outside the extension's control. Disable Protect this site to restore ordinary playback; disable keyboard controls to retain a site's shortcuts.

Privacy and limits

Website access is used only for local media detection and control. Preferences and session pause state remain in the browser. Anchor has no telemetry, server, network requests, remote code, or browsing-history log. Session records are deleted when a tab closes.

Anchor supports standard HTML video/audio players and does not repair server outages, network buffering, unsupported codecs, DRM failures, or native apps. It does not skip ads or bypass DRM. Platform updates and unusual custom controls may need adjustments.

Pause state is shared across frames and retained across same-site reloads during a browser session. It clears when you explicitly play, disable protection, close the tab, change origins, or restart the browser.
